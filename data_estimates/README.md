# Data estimates

Order-of-magnitude storage planning for Personal Groktor.

| File | Contents |
|------|----------|
| [`personal_health_storage_per_year.txt`](personal_health_storage_per_year.txt) | One person’s health/wearable data per year |
| [`medical_research_agent_storage.txt`](medical_research_agent_storage.txt) | Corpus + working set for an agent that reads current medical research and checks authenticity signals |

Figures are **engineering estimates**, not measurements from production traffic. Assumptions and ranges are in each file. Prefer the “likely Personal Groktor” rows when sizing a single-user install.

Design that consumes these numbers: [`docs/research_agent_v0.md`](../docs/research_agent_v0.md), [`docs/schema_cli.md`](../docs/schema_cli.md).
