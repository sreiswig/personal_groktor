# Open medical papers

Inventory of **free and open** places to find healthcare / biomedical literature — for grounding Personal Groktor features (metrics, rules, digests) in public research. This is a source list only; nothing here is clinical advice.

## Files

| File | Purpose |
|------|---------|
| [`sources.txt`](sources.txt) | Plain-text catalog of free/OA paper sources, preprints, APIs, and evidence sites |

## Use with this project

- Prefer **peer-reviewed OA** or clear preprint labels when citing methods (e.g. HRV baselines, sleep debt).
- Check **license** before redistributing PDFs or building datasets.
- Pair with local analysis: literature informs rules; **your** wearable data stays on your machine.

## Not in scope

- Paywalled-only journals without a free path  
- Shadow libraries / unauthorized full-text sites  
- Treatment recommendations for users
